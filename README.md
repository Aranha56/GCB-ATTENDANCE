# GCB Estonia — Training Attendance

Готовое статическое веб-приложение для GitHub Pages.

## Что уже работает
- Календарь по месяцам и выбор даты.
- Выбор группы.
- Отметка присутствовал / отсутствовал.
- Статистика по ученику: количество и процент.
- Добавление / редактирование / удаление ученика.
- Создание / переименование / удаление группы.
- Перевод ученика между группами.
- Профиль ученика, телефон, заметки, история посещений.
- Экспорт и импорт резервной копии JSON.
- PWA: можно добавить сайт на главный экран iPhone.
- Локальный режим работает сразу после публикации.

## Чтобы данные синхронизировались между iPhone и MacBook
GitHub Pages хранит только сайт, поэтому для общей базы данных нужен облачный backend. В проект уже встроена поддержка **Firebase Authentication + Cloud Firestore**.

1. Откройте Firebase Console и создайте проект.
2. В `Authentication` включите `Email/Password`.
3. Создайте `Cloud Firestore`.
4. В `Project settings` → `Your apps` создайте Web App.
5. Скопируйте `firebaseConfig` и вставьте значения в файл `firebase-config.js`.
6. В Firestore → Rules вставьте содержимое файла `FIRESTORE_RULES.txt` и опубликуйте.
7. Загрузите весь проект в GitHub и включите GitHub Pages.
8. Откройте Pages-ссылку и создайте аккаунт. На iPhone и MacBook входите под одним и тем же email/паролем.

После этого изменения на одном устройстве будут появляться на другом через Firestore realtime sync.

## GitHub Pages
Загрузите содержимое папки в корень репозитория. Затем:
`Settings` → `Pages` → `Deploy from a branch` → `main` / root.
